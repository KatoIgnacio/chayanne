Instalar XAMPP
Cambiar puerto si necesita (8080)
Copiar proyecto a C:\xampp\htdocs\chayanne
Crear C:\xampp\chayanne_config\config.php a partir de config.example.php

Iniciar Apache
Abrir:
http://localhost:8080/chayanne/health.php
http://localhost:8080/chayanne/upload.php
http://localhost:8080/chayanne/batch.php

Puntos clave para Cloud SQL:
En Cloud SQL debe estar autorizada la IP publica del companero en Authorized networks
Asegurar usuario/password correctos
Puerto 3306
